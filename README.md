# Sistema de Evolução

Aplicação web pessoal de gamificação para acompanhar hábitos, estudos, treino e evolução profissional. A interface transforma objetivos em missões, atributos, níveis, conquistas e histórico de progresso.

## Demonstração local

O projeto está nesta versão como um protótipo autocontido em HTML, CSS e JavaScript. Para testar, baixe `index.html` e abra no navegador. Não há etapa de instalação ou servidor necessário. O navegador precisa permitir armazenamento local para manter os dados entre acessos.

## Recursos

- Painel de progresso com nível, atributos e experiência.
- Missões e metas organizadas em uma interface inspirada em RPG.
- Conquistas, títulos, registros e elementos desbloqueáveis.
- Preferência visual adaptável ao desempenho do dispositivo.
- Dados mantidos localmente no navegador.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- `localStorage` para preferências e dados locais

## Estado do projeto

Protótipo individual em evolução. Esta publicação contém a versão V3.6 Adaptive Optimized II, salva como uma página única. Ainda não possui backend nem sincronização entre dispositivos.

## Privacidade

Os dados da aplicação ficam no armazenamento local do navegador usado para executá-la. Limpar os dados do site ou trocar de navegador/perfil pode apagar ou tornar esses dados indisponíveis. O projeto não inclui credenciais ou dados pessoais de usuário.

## Como contribuir ou reportar problemas

Abra uma issue com os passos para reproduzir o problema, o navegador utilizado e o comportamento esperado.
